Steps to Generate an Allure Report with Playwright
Step 1: Configure the reporters in playwright.config.js

Add this inside defineConfig to generate both the Playwright HTML report and Allure results:
reporter: [
  ['html', { outputFolder: 'playwright-report', open: 'never' }],
  ['allure-playwright', { resultsDir: 'allure-results' }]
],
Make sure allure-playwright and allure are installed in the project. (Allure Playwright setup)

Step 2: Run your tests
npx playwright test
To run only Chromium with the browser visible:
npx playwright test --project=chromium --headed

Step 3: Generate the Allure HTML report
npx allure generate .\allure-results

Step 4: Open the report
npx allure open .\allure-report
